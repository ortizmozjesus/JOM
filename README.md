# Jesús Ortiz Muñoz · portfolio

Web: https://ortizmozjesus.github.io/JOM/ — arquitectura y software: proyectos, dibujo y herramientas propias que funcionan en el navegador.

- `index.html`, `proyectos.html`, `proyectos/*.html` (un caso por proyecto), `herramientas.html`, `sobre-mi.html`, `contacto.html`, `perfil-estudio.html`, `perfil-software.html`
- `herramientas/`: Forja, Ondas de Lora, Modelo Cerezales, Modelo Curueño-Porma, Estanque de piedras, Campo de niveles, Agente de facturas (vista previa), Forja app y Visor IFC
- `assets/`: CSS (`studio.css` + `motion.css`), JS (`site.js` + `motion.js`), fuentes locales, imágenes y CV
