Cómo funciona

  1. That Open Engine convierte el IFC a Fragments y lo dibuja con Three.js.
  2. web-ifc lee los conjuntos de cantidades (Qto), los Pset y la planta de cada elemento.
  3. Unas reglas asignan cada elemento a una partida: clase IFC, tipo, si es exterior, espesor.
  4. Se escribe el BC3 con raíz, capítulos, partidas, texto y mediciones.
